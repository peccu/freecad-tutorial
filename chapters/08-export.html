書き出し

FreeCAD の形状をスライサーへ渡す。形式によって中身が違い、曲面の精度やファイルの扱いやすさが変わる。

形式の選び方

形式中身単位使う場面
STEP正確な曲面（B-rep）持つBambu Studio 側で曲面の細かさを決めたい。他の CAD にも渡したい
3MF三角形メッシュ＋色・複数部品持つ複数の部品をまとめて渡したい
STL三角形メッシュのみ持たないどのスライサーでも読める。もっとも単純

迷ったら 3MF。単位を持つので、大きさの取り違えが起きない。曲面の多い部品で仕上がりにこだわるなら STEP も試す価値がある。

STL には単位がない。Bambu Studio は mm として読むため、インチで作られた STL は極端に小さく表示される（読み込み時に変換を提案される）。

メッシュの細かさ

STL・3MF では、曲面が細かい平面（三角形）の集まりに置き換えられる。元の曲面からのずれ（偏差Deviation）の上限で細かさが決まる。

3Dプリントでは偏差 0.01〜0.05mm 程度で十分。プリンタの線幅（0.4mm 前後）より十分小さければ、それ以上細かくしても印刷結果は変わらない。

FreeCAD での設定場所：Preferences → Import-Export → Mesh Formats設定 → インポート/エクスポート → メッシュ形式の「最大メッシュ偏差」Maximum mesh deviation。Mesh Design ワークベンチのCreate mesh from shape形状からメッシュを作成を使うと、書き出しごとに偏差を指定できる。

書き出しの手順

  1. モデルツリーでボディを選ぶ（中のフィーチャではない）。複数部品なら Ctrl+クリックで追加
  2. File → Exportファイル → エクスポート（Ctrl+E）
  3. ファイルの種類で「3D Manufacturing Format (*.3mf)」または「STL Mesh (*.stl)」を選ぶ
  4. ファイル名を付けて保存する
  1. ボディを選ぶ
  2. File → Exportファイル → エクスポートで「STEP (*.step *.stp)」を選んで保存
  3. Bambu Studio で読み込むと、メッシュ化の細かさ（線形・角度の偏差Linear / Angle deflection）を指定する画面が出る

スライサーで形の一部が欠けている → 書き出したのがボディではなく、途中のフィーチャだった可能性が高い。ボディを選び直して書き出す。

書き出したあとの確認

メッシュに穴や裏返った面があると、スライスが乱れることがある。Part Design で作った正常なボディなら、ほぼ起きない。

確認方法見るところ
Bambu Studio に読み込む読み込み時の修復メッセージ、オブジェクト一覧の警告マーク
FreeCAD の Mesh DesignMeshes → Analyze → Evaluate and repair meshメッシュ → 解析 → 評価と修復で、穴・重複・裏返りを検査
FreeCAD の Part ワークベンチ書き出す前に、ボディを選んでPart → Check geometryパート → ジオメトリをチェック

形状の大きさを取り違えにくい書き出し形式はどれか。

3MF と STEP は単位を持つ。STL は数値だけなので、読み込み側の解釈に依存する。
