FreeCAD の基本操作

画面の構成、ワークベンチ、視点の動かし方、最初に済ませておく設定。FreeCAD は機能が多く、最初は「どこを見ればよいか」で迷いやすい。

画面の構成

実際に手を動かすのは、ほとんどが 3Dビュー・モデルツリー・タスクパネルの3か所。ツールを起動するとコンボビューがTasksタスクタブに切り替わり、そこで数値を入れて OK で確定する。

パネルを閉じてしまったらView → Panels表示 → パネルから、ツールバーが消えたらView → Toolbars表示 → ツールバーから戻す。

ワークベンチ

FreeCAD は目的ごとのツール群（ワークベンチ）を切り替えて使う。3Dプリント用の部品は、ほぼ Part Design だけで作れる。

ワークベンチ用途本書での扱い
Part Designスケッチから1つの立体を積み上げて作る中心（第4章）
Sketcher2D のスケッチを描く。Part Design から自動で呼ばれる第3章
Part直方体・円柱などの基本形状とブーリアン演算干渉確認で少し使う
Assembly複数部品をジョイントで組む第7章
Mesh Designメッシュの確認・修正第8章
Spreadsheet寸法を表で管理する第5章
TechDraw2D 図面の作成扱わない

Part ワークベンチの直方体と Part Design のボディを混ぜて使い、後から修正できなくなる。最初のうちは「ボディを作ってからスケッチ」の流れに統一する。

最初に済ませる設定

設定画面は Windows・Linux ではEdit → Preferences編集 → 設定、macOS ではFreeCAD → PreferencesFreeCAD → 設定。1.1 から設定画面に検索欄が付いた。

  1. 単位系Unit system　General一般→ 単位系を Standard (mm, kg, s, °) にする。小数点以下の桁数は 2 以上
  2. ナビゲーションスタイルNavigation style　Display → Navigation表示 → ナビゲーションで、手になじむスタイルを選ぶ。迷ったら CAD
  3. バックアップBackup files / AutoRecovery　General → Document一般 → 文書で、保存時のバックアップファイル数を 2〜3 に。自動保存（復旧情報）も有効にする
  4. 言語Language　General一般→ 言語。メニュー名を英語の解説と照らし合わせたいときは English に切り替える

設定項目の場所は版によって移動することがある。見つからないときは設定画面の検索欄に「単位」「バックアップ」などと入れる。

ファイルと保存

.FCStd
FreeCAD の文書ファイル。形状・履歴・スプレッドシートがまとめて入る。中身は ZIP 形式。
.FCBak
保存時に自動で作られる1つ前の版。拡張子を .FCStd に変えると開ける。
再計算Recompute
寸法を変えたあと形状を作り直す処理。ツールバーの再計算ボタン、または Ctrl+R。ツリーに青い再計算マークが付いたものが対象。
元に戻すUndo
Ctrl+Z。スケッチ編集中は、スケッチ内の操作だけが対象になる。

3Dプリンタ用に書き出す STL・3MF とは別に、元の .FCStd を必ず残す。寸法の修正は .FCStd 側で行う。
